⚙️ VedRol — Assistente Técnico de Rolamentos

Assistente técnico desenvolvido em Python com inteligência artificial, utilizando Streamlit para a interface web e a API da Groq para gerar respostas sobre rolamentos industriais, vedações e componentes de transmissão mecânica.

📌 Sobre o projeto

O VedRol é uma aplicação que busca auxiliar profissionais da indústria, técnicos de manutenção, mecânicos, compradores e vendedores na consulta de informações técnicas sobre rolamentos.

O sistema utiliza instruções especializadas para orientar a identificação de códigos, explicar características de componentes e apresentar aplicações industriais comuns.

Objetivo: desenvolver uma interface de consulta técnica com inteligência artificial, facilitando o acesso a informações sobre componentes mecânicos.

✨ Funcionalidades

💬 Chat interativo com inteligência artificial.

⚙️ Orientações sobre rolamentos industriais e suas famílias.

🔎 Auxílio na interpretação de códigos de rolamentos.

🏭 Informações sobre aplicações industriais.

🧰 Orientações gerais sobre mancais, vedações e acessórios.

📝 Histórico de mensagens durante a sessão.

🧹 Opção para limpar a conversa.

🎨 Interface personalizada com identidade visual da VedRol.

🔐 Configuração da chave da API por meio de variáveis de ambiente.

Observação: as respostas são geradas por IA e devem ser verificadas em catálogos técnicos dos fabricantes. O sistema não possui integração automática confirmada com catálogo comercial, estoque ou preços da VedRol.

🛠️ Tecnologias utilizadas

Python — linguagem principal.

Streamlit — desenvolvimento da interface web.

Groq API — integração com o serviço de inteligência artificial.

Pillow (PIL) — manipulação e carregamento de imagens.

python-dotenv — carregamento de variáveis de ambiente.

CSS3 — personalização do estilo visual.
